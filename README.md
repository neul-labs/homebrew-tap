# neul-labs/homebrew-tap

Homebrew tap for [neul-labs](https://github.com/neul-labs) tools.

## Installation

```bash
brew tap neul-labs/tap
brew install rninja
```

## Available Formulae

- **rninja** - A drop-in replacement for Ninja build system with caching and improved scheduling

## Updating

```bash
brew update
brew upgrade rninja
```
